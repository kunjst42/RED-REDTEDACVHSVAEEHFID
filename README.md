======= RED: REDTEDACVHSVAEEHFID =======

Простой 2D-симулятор редстоун-механизмов и логических схем. Стройте свои механизмы из проводов, поршней, повторителей и датчиков прямо на сетке.

========================================
## 🇷🇺 Русский
========================================

### Управление:
* **ЛКМ (левая кнопка)** — поставить блок / нажать кнопку или рычаг
* **ПКМ (правая кнопка)** — удалить блок
* **СКМ (колесико)** — зажать для перемещения камеры, крутить для зума
* **1 – 9** — быстрый выбор предмета на панели
* **Tab** — переключить вкладку (Механизмы / Блоки)
* **R** — повернуть выбранный механизм
* **Q** — инструмент выделения
* **E** — ластик
* **Delete** — удалить всё выделенное
* **Ctrl + S / Ctrl + O** — сохранить / загрузить схему
* **Esc** — меню паузы и настройки

### Запуск:
* Запустите **`red_drava.exe`**

========================================
🇬🇧 English
========================================

A simple 2D simulator for Redstone mechanisms and logic circuits. Build machines using wires, repeaters, pistons, and sensors.

### Controls:
* **LMB** — Place block / Toggle switch or button
* **RMB** — Remove block
* **MMB (Wheel)** — Hold to pan camera, scroll to zoom
* **1 – 9** — Select tool
* **Tab** — Switch category (Mechanisms / Blocks)
* **R** — Rotate selected component
* **Q** — Selection tool
* **E** — Eraser
* **Delete** — Delete selected area
* **Ctrl + S / Ctrl + O** — Save / Load circuit
* **Esc** — Pause & Settings

### How to Run:
* Run **`red_drava.exe`**

## 🇨🇳 中文
========================================

一个简单的 2D 红石机械与逻辑电路模拟器。使用电线、活塞、延迟器和传感器建造你的机械。

### 操作说明:
* **鼠标左键** — 放置方块 / 切换开关或按钮
* **鼠标右键** — 删除方块
* **鼠标中键（滚轮）** — 按住拖动视野，滚动缩放
* **1 – 9** — 选择工具
* **Tab** — 切换分类（机械 / 方块）
* **R** — 旋转选中的元件
* **Q** — 框选工具
* **E** — 橡皮擦
* **Delete** — 删除选区内容
* **Ctrl + S / Ctrl + O** — 保存 / 加载电路
* **Esc** — 暂停与设置

### 启动方法:
* 直接运行 **`red_drava.exe`**
